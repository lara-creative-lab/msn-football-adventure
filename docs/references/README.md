## `physical-badge-shape-reference.png`

实体徽章合集。使用时关注：

- 徽章轮廓随主题变化，而不是全部使用同一圆形外框。
- 可混合珐琅、拉丝金属、镀金、镀银、浮雕和局部镂空效果。
- 地标、花卉、动物、文字牌和体育符号可决定徽章整体外形。
- 参考其设计语言，不要逐枚复制照片中的现有商标或赛事徽记。
