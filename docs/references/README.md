# 视觉参考图

这些文件是项目长期资料，不应再依赖原始剪贴板临时路径。

## `asset-preview-remove-text.png`

资产放大层截图。红框中的 `ASSET VIEW` 是已确认需要删除的文案；关闭按钮、资产主体、标题和说明不在这条决定的删除范围内。

## `physical-badge-shape-reference.png`

实体徽章合集。使用时关注：

- 徽章轮廓随主题变化，而不是全部使用同一圆形外框。
- 可混合珐琅、拉丝金属、镀金、镀银、浮雕和局部镂空效果。
- 地标、花卉、动物、文字牌和体育符号可决定徽章整体外形。
- 参考其设计语言，不要逐枚复制照片中的现有商标或赛事徽记。

## `home-red-box-remove-text.png`

游戏主页截图。红框中的开始按钮下方说明文字需要整段删除；关卡选择、场景选择和开始按钮不在删除范围内。

`home-red-box-remove-text-v2.png` 是同一删除范围的后续清晰截图，并补充要求删除后将保留内容整体下移。

## 资产页城市徽章与分类标签反馈

- `asset-page-city-badges-and-labels-feedback.png`：确认旧版十枚通用圆形徽章仍未替换，并指出右上角收藏分类不应做成像按钮一样的深色胶囊。
- `asset-label-epic-feedback.png`、`asset-label-journey-feedback.png`、`asset-label-easter-egg-feedback.png`：三种低对比度胶囊标签的局部截图。后续实现应采用无底色、不可点击、高对比文字标签。

## `star-card-ranking-labels-feedback.png`

球星卡标签反馈截图。`ICON / GOAT / SAMBA / ELITE / GOLD / LEGEND` 会形成主观的球星高低比较；球星卡右上角应改用客观的场上位置标签。
